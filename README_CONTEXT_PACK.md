# Контекстный пакет для Claude Code — «Личности»

Репозиторий назначения: https://github.com/bassixs/person.git

## Установка

Распакуй архив **в корень репозитория**, сохранив структуру:

```
person/
├── CLAUDE.md
├── LICHNOSTI_Claude_Code_TZ.md
├── README_CONTEXT_PACK.md
└── docs/
    ├── PROJECT_CONTEXT.md
    └── DECISIONS.md
```

Затем в Claude Code попроси прочитать `CLAUDE.md` и оба основных документа целиком, перечислить уже утверждённые решения и **начать итерацию 1**, а не ограничиваться планом.

`docs/PROJECT_CONTEXT.md` — «память», мотивация и все продуктовые договорённости.  
`LICHNOSTI_Claude_Code_TZ.md` — инженерное ТЗ.  
`CLAUDE.md` — короткая инструкция, автоматически полезная Claude Code при открытии репозитория.  
`docs/DECISIONS.md` — будущие решения, после начала разработки.

Если разработка уже началась, не перезаписывай существующий `CLAUDE.md` без сравнения содержимого и объединения инструкций.
