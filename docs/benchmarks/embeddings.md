# Замер эмбеддинг-моделей AITUNNEL (2026-11-20)

Задача — смысловой поиск по материалам Контекстного центра на русском: жители спрашивают своими словами, документы написаны официальным языком. Нужно для поиска с цитатой, отбора кусков документов для ИИ (RAG), подбора темы к обращению из MAX, дедупликации находок мониторинга.

## Набор

`scripts/bench/embeddings_ru.json` — 60 коротких документов (объявления администрации, газетные заметки, жалобы, регламенты) по одному району и 50 запросов в стиле жителей. Набор специально «жёсткий»: два моста (Лесная и Полевая), две школы, похожие жалобы на освещение на разных улицах, старые и новые даты. Запросы — пересказ без общих слов с документом, разговорные комментарии («Опять обманули! Обещали к 25-му…»).

Повторить: `python scripts/bench/embeddings.py . scripts/bench/embeddings_ru.json out.json` (ключ берётся из `.env`).

Hit@1 — нужный документ первым; Recall@5 — нужное в первой пятёрке; MRR — насколько высоко в среднем стоит первый нужный. Поиск по словам на пересказах почти всегда возвращает пустой ответ (48 из 50) — поэтому смысловой поиск нужен, а не «улучшение».

Часть промахов лидеров — честная неоднозначность запроса («сколько тратят на ремонт» — какой из двух мостов).

**Размер вектора.** pgvector строит индекс HNSW для `vector` до 2000 измерений. pplx-embed поддерживает параметр `dimensions`: при 1024 качество то же (Hit@1 0.94, MRR 0.967). Qwen3 при 1024 чуть теряет (0.88).

## Предложение

- **Основная модель: `pplx-embed-v1-4b`, 1024 измерения.** Лучшая точность, быстрый ответ (важно для поиска и MAX), 6 ₽ за 1M токенов: тысяча документов по 10 страниц (~30M токенов) — около 180 ₽ разово.
- Запасная: `gigachat-embeddings-2` (российский провайдер, 1024, но окно 512 токенов — куски мельче) или `qwen3-embedding-8b` (дёшево, но медленно для интерактива — годится для фоновой индексации).
- Поиск — гибридный: смысловой + полнотекстовый (точные номера, даты, названия), без ключа — только полнотекстовый, с честным статусом.
- Реранк (`rerank-*` в AITUNNEL) — отдельным замером, если понадобится.
