# UI/UX (итерация 1)

- **Стиль** (E-021, с 2026-11-17 — единый с отчётом `/about`): светлая «бумага» `#F1EFE8`, карточки `#FBFAF6`,
  чернила `#141414`, сигнальный оранжевый `#EA501A`. Все цвета — CSS custom properties в
  `apps/web/src/styles/tokens.css`; Tailwind ссылается на них. Прежняя тёмная атмосфера NestJS заменена.
- **Семантика статусов** (success / warning / danger / info) отделена от акцента и затемнена под светлый фон.
- **Шрифты**: заголовки h1–h3 и метки — Unbounded, текст — Manrope, версии и хэши — Geist Mono; всё с кириллицей,
  self-hosted через @fontsource.
- **Знак** (E-022): веер из трёх карточек персонажей с оранжевой «искрой» (`components/Logo.tsx`, `public/mark.svg`, PNG-фавиконы — `apps/web/scripts/render-mark.mjs`); в шапке — текстовое название. Финальный логотип не утверждён.
- **Навигация**: плавающая верхняя панель со скруглением, как в отчёте; активный раздел — мягкая подсветка; на мобильных —
  раскрывающееся меню. Глобального левого sidebar нет.
- **Портреты персонажей**: у семи исходных легенд — стилизованные 3D-портреты (`public/personas`), в каталоге
  они служат обложкой карточки. Живой фон тёмной темы снят; `prefers-reduced-motion` отключает анимации.
- **Рабочая карточка**: ≥1280px — три колонки (разделы · поля и нарратив · ИИ-панель); 1024–1279px — две, ИИ-панель
  в drawer; <1024px — разделы и ИИ в drawer. Ctrl+S — сохранить; предупреждение при уходе с несохранёнными
  правками; баннер конфликта ревизий.
- **Честность**: модули следующих итераций показаны как «не подключено / итерация N», без выдуманных цифр.
