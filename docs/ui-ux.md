# UI/UX (итерация 1)

- **Атмосфера** NestJS-inspired: canvas `#050303`, поверхности `#0B0B0B` / `#181818`, crimson `#EA2845`, garnet
  `#780F20`. Все цвета — CSS custom properties в `apps/web/src/styles/tokens.css`; Tailwind ссылается на них.
- **Семантика статусов** (success / warning / danger / info) отделена от фирменного crimson.
- **Шрифты**: Manrope (UI), Geist Mono (версии, даты, метки) — с кириллицей, self-hosted через @fontsource.
- **Знак**: оригинальный заменяемый знак (`components/Logo.tsx`), финальный логотип не утверждён.
- **Навигация**: фиксированная верхняя панель с дымчатым стеклом; на мобильных — раскрывающееся меню. Глобального
  левого sidebar нет. Левая колонка рабочей карточки — локальная навигация по разделам.
- **Живой фон** (`Ambient.tsx`): три медленно дрейфующих размытых пятна (46–74 с), шесть редко мерцающих точек,
  зерно, виньетка. На «Обзоре» — полная интенсивность, в рабочих разделах — около 38 %.
  `prefers-reduced-motion` — статично; скрытая вкладка — анимации на паузе.
- **Рабочая карточка**: ≥1280px — три колонки (разделы · поля и нарратив · ИИ-панель); 1024–1279px — две, ИИ-панель
  в drawer; <1024px — разделы и ИИ в drawer. Ctrl+S — сохранить; предупреждение при уходе с несохранёнными
  правками; баннер конфликта ревизий.
- **Честность**: модули следующих итераций показаны как «не подключено / итерация N», без выдуманных цифр.
