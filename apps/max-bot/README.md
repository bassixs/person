# max-bot

MAX-бот — интерфейс оператора; источник истины — общий backend (`apps/api`).

Состояние (итерация 1):
- адаптер конфигурации и проверки соединения: `apps/api/app/integrations/max.py`
  (`MAX_BOT_TOKEN`, домен `platform-api2.max.ru`, заголовок `Authorization`);
- без токена система показывает «MAX не подключён»; переписка ботом не имитируется.

Итерация 5: привязка сотрудника через разовый код, меню «Новое задание / Мои задания / Темы / Помощь»,
быстрый и пакетный режимы, два входа (сначала контекст / сначала материал), фиксация версий в задании.
Перед реализацией сверить методы и webhook/polling с https://dev.max.ru/docs-api.

Бот не публикует сообщения в публичные обсуждения и не управляет сторонними аккаунтами.
